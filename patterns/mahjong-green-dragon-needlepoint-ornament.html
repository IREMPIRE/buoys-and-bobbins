Mahjong Green Dragon Ornament

Mahjong Ornament Needlepoint Pattern, Green Dragon Tile Chart PDF, 18 Mesh

Instant download

Buy on Etsy

Mahjong Green Dragon Ornament needlepoint pattern (PDF): The green dragon, 發, in green on an ivory tile with a green edge, set on pink and white stripes with a navy border: a 4-inch square ornament for 18 mesh.

Instant download. A digital pattern: a PDF chart, a ZIP of 2 PNG files (true size for 18 mesh, and Stitchly-ready), and the Stitchly-ready PNG on its own. Not a painted canvas or kit; nothing is shipped.

How to download

Open etsy.com in a web browser (the Etsy app can't download files) > You > Purchases > Download files.

You get

  • 13-page PDF: color chart, printer-friendly symbol chart, thread list, how-to, and true-size pages for tracing
  • ZIP: 1 true-size PNG for 18 mesh; 1 Stitchly-ready PNG, 1 pixel = 1 stitch; a DMC color list to check the import against; and step-by-step Stitchly import notes
  • The Stitchly-ready PNG as its own download too (the same file as in the ZIP): save it straight to your phone, no unzipping.
  • A DMC thread list: every floss number, color name and skein estimate on one page.

Size (stitched area)

  • Green Dragon Mahjong Ornament: 4.0" x 4.0" on 18 mesh (72 x 72 stitches)

You'll need

  • Blank 18 mesh canvas (the PDF gives the size to cut)
  • 8 DMC floss colors (numbers and skein estimates are in the PDF)
  • A tapestry needle; acrylic paint and a canvas marker if you paint your own canvas

Skill: Confident beginner (8 colors and a few small details)

Using the Stitchly app

  • The Stitchly-ready PNG is 1 pixel = 1 stitch: 72 x 72 stitches, 8 DMC colors (both are in its file name).
  • In Stitchly, choose Convert a photo, set the size to 72 x 72, pick DMC and 8 colors. Step-by-step notes are in the download.
  • It's a PNG image, not a .stitchly project file. Stitchly is a separate app, sold separately, and importing may need its full version. This shop isn't affiliated with it.

Save with the set

All 3 designs come in one download: look for "Mahjong Ornament Needlepoint Patterns" in my shop.
