Mahjong Dragon Ornament

Mahjong Ornament Needlepoint Patterns, Set of 3 Dragon Tile Charts PDF, 18 Mesh

Instant download

Buy on Etsy

Mahjong Dragon Ornament needlepoint patterns (set of 3, PDF): All three dragon tiles in one download: red 中, green 發 and white, each a 4-inch square ornament for 18 mesh. A set for the mahjong table or the tree.

Instant download. A digital pattern: a PDF chart and a ZIP of 6 PNG files (true size for 18 mesh, and Stitchly-ready). Not a painted canvas or kit; nothing is shipped.

How to download

Open etsy.com in a web browser (the Etsy app can't download files) > You > Purchases > Download files.

You get

  • 34-page PDF: color chart, printer-friendly symbol chart, thread list, how-to, and true-size pages for tracing
  • ZIP: 3 true-size PNGs for 18 mesh (one per design); 3 Stitchly-ready PNGs, 1 pixel = 1 stitch (one per design); a DMC color list per design to check the import against; and step-by-step Stitchly import notes
  • A DMC shopping list for all 3 designs: every floss number once, with skein estimates for the whole set, on one page; each design's own thread list too.

Size (stitched area)

  • Red Dragon Mahjong Ornament: 4.0" x 4.0" on 18 mesh (72 x 72 stitches)
  • Green Dragon Mahjong Ornament: 4.0" x 4.0" on 18 mesh (72 x 72 stitches)
  • White Dragon Mahjong Ornament: 4.0" x 4.0" on 18 mesh (72 x 72 stitches)

You'll need

  • Blank 18 mesh canvas (the PDF gives the size to cut)
  • 13 DMC floss colors (numbers and skein estimates are in the PDF)
  • A tapestry needle; acrylic paint and a canvas marker if you paint your own canvas

Skill: Confident beginner (8 to 9 colors per design and a few small details)

Using the Stitchly app

  • Each Stitchly-ready PNG is 1 pixel = 1 stitch; its size and number of DMC colors are in its file name.
  • In Stitchly, choose Convert a photo and type in that size and color count. Step-by-step notes are in the download.
  • It's a PNG image, not a .stitchly project file. Stitchly is a separate app, sold separately, and importing may need its full version. This shop isn't affiliated with it.

License

Personal use: paint and stitch it for yourself and as gifts. Please don't share or resell the files, sell canvases painted from them, or use them for mass production.

Colors on screen are approximate; check them against a DMC color card. Because this is a digital download it can't be returned, but if anything is wrong with your file, message me and I'll make it right.
